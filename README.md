# Aniimo · Noite Mágica

[Abrir o guia Noite Mágica](https://qevzi.github.io/aniimo-noite-magica/)

Planeje a decoração do RV para atingir 70 mil pontos de habitabilidade no evento Noite Mágica. O guia permite ajustar os móveis disponíveis, comparar trocas e consultar códigos de decoração por servidor. Disponível em português, inglês e japonês.

O site é estático. Abra `index.html` no navegador para testar localmente e mantenha os GIFs do tutorial na mesma pasta.

Projeto de fã mantido por qevzi, desenvolvido com auxílio do OpenAI Codex.
